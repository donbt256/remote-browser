Local noVNC Viewer

The viewer files run locally. Use the controls below to start, check, or stop the GitHub Actions browser session.

Enter your BROWSER_PASSWORD in the Browser password field below before using these controls. The same password decrypts the Actions token and logs in to the remote desktop. The encrypted token is downloaded from this public repository; the password and decrypted token are not saved.
